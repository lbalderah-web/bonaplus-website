# Productos Bonaplus — sitio web listo para publicar

## Vista local
Abre `index.html` en el navegador.

## Publicación recomendada
Sube el contenido completo de esta carpeta a Netlify, Vercel, Cloudflare Pages o al hosting del dominio. El archivo principal es `index.html`.

## Antes de conectar el dominio
- Confirmar que el correo y teléfono sean los definitivos.
- Configurar el dominio y certificado SSL desde el proveedor de hosting.
- Opcional: agregar Google Analytics o Meta Pixel únicamente con el consentimiento correspondiente.

El catálogo no muestra precios y genera solicitudes de pedido por WhatsApp.
